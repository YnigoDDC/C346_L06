# The Camellia Quiz App

An app that quizzes you on Camellia's music albums

# Features Highlight

- **Interactive Quiz:** Users can answer three multiple-choice questions about Camellia's albums
- **Image Display:** Each question includes an album cover to help users identify it
- **Reusable Components:** FullQuestion component reduces code repetition
- **State Management:** useState stores the user's selected answers
- **Answer Validation:** Checks submitted answers against the correct answers and calculates the score
- **Feedback:** Alert.alert() displays the user's final score with a customized message
